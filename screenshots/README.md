# Study Pilot — Interface Previews

This directory contains visual captures of the Study Pilot interface running on Windows with live university LMS data.

---

### Recommended Preview Assets
To capture and update these preview assets:
1. Run the application via `.\run_dev.ps1`.
2. Open `http://localhost:3000`.
3. Capture full-window or viewport screenshots into this folder with the following filenames:

| Filename | View Description |
| :--- | :--- |
| `01_dashboard.png` | **Executive Dashboard**: Course counts, upcoming deadlines, and live sync status. |
| `02_courses.png` | **Course Directory**: Active semester courses partitioned from archived past courses. |
| `03_activities.png` | **Activity Registry**: Filterable table of 141 activities with status badges and Moodle links. |
| `04_calendar.png` | **Strict Deadline Calendar**: Chronological timeline of assignments with verified due dates. |
| `05_settings_sso.png` | **SSO Connection Manager**: Microsoft Edge authentication status and session health diagnostics. |

---

*Note: Previews should have personal student identification numbers redacted before public commit.*
